# bracehive

Brace CSV/TSV hive tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/bracehive/

## Install / run

```bash
git clone https://github.com/theworker02/bracehive.git
cd bracehive
node src/cli.js
node --test
```
